# L3-SE Demo Page

This repository hosts the demo page for the under-review manuscript titled:

**Reducing Linguistic Hallucination in LM-Based Speech Enhancement via Noise-Invariant Acoustic-Semantic Distillation**

The complete source code will be released after the manuscript is accepted.

## Contents

- `Appendix.pdf`: supplementary appendix
- `index.html`: demo page entry point
- `wer.json`: metadata and transcription results used by the demo page
- `audio/`: audio samples used by the demo page

## Online Demo Page

The repository can be hosted with GitHub Pages or any static web server to provide online access to the demo page.

**Demo URL:** `https://max1wz.github.io/L3-SE-Demo-Page/`

## Usage

To view the demo page locally, clone or download this repository and open `index.html` in a web browser. Keep `index.html`, `wer.json`, and the `audio/` folder in the same directory.

If local file access is restricted by the browser or review environment, please use the online demo page link above.
